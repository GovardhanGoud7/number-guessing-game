# Number Guessing Game

A command-line guessing game written in Python. Pick a difficulty, guess the secret number, and beat your high score.

## Features
- Three difficulty levels: Easy (1-50), Medium (1-100), Hard (1-500)
- "Higher/lower" and hot/cold hints after every guess
- Score based on how few guesses you use
- High scores saved between games

## How to run
1. Install Python 3
2. Download `number-guessing-game.py`
3. Run: `python number-guessing-game.py`

## How to play
Choose a level (1-3), type your guesses, and follow the hints. Type `q` at the menu to quit.
